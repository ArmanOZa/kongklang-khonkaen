# ⚡ ระบบจัดการกองกลาง แผนกมิเตอร์และหม้อแปลง (ผมต.กฟจ.ขอนแก่น)

ระบบเว็บแอปพลิเคชันสำหรับบริหารจัดการเงินกองกลาง บันทึกสถานะการชำระเงินของสมาชิก พร้อมระบบแนบสลิปโอนเงิน และบันทึกประวัติรายจ่ายประจำเดือน เชื่อมต่อฐานข้อมูลแบบ Real-time ด้วย Firebase Firestore

---

## 📋 ฟังก์ชันหลักของระบบ
* **📅 ระบบเลือกประจำเดือน:** สามารถสลับดูข้อมูลย้อนหลังหรือเดือนปัจจุบันได้อย่างสะดวกรวดเร็ว
* **📊 สรุปภาพรวมการเงิน (Dashboard):** 
  * ยอดรับเงินกองกลางทั้งหมด
  * รายจ่ายรวมประจำเดือน
  * ยอดเงินคงเหลือในกองกลาง
  * ยอดค้างชำระประจำเดือน
* **👥 ตารางสมาชิกและสถานะการชำระเงิน:** 
  * แสดงรายชื่อ ตำแหน่ง และอัตราเงินกองกลางของแต่ละบุคคล
  * สถานะจะเปลี่ยนเป็น **"✅ ชำระแล้ว"** อัตโนมัติเมื่อมีการแนบสลิปหลักฐานการโอน
  * สามารถกดดูสลิปเงินโอนของสมาชิกแต่ละคนได้ทันที
* **💸 ระบบบันทึกรายจ่าย:** บันทึกรายการรายจ่ายพร้อมแนบใบเสร็จ/หลักฐาน และสามารถลบรายการได้
* **📱 QR Code พร้อมเพย์:** ปุ่มเรียกดู QR Code พร้อมเพย์สำหรับการโอนเงินเข้าบัญชี (พร้อมเบอร์โทรและชื่อบัญชี)
* **🔒 ระบบรหัสความปลอดภัย:** ป้องกันการทำรายการสำคัญ (เปลี่ยนสถานะ, แนบสลิป, เพิ่ม/ลบรายจ่าย, เปิด QR Code) ด้วยรหัสผ่าน **`14045`**
* **⏳ ตัวนับถอยหลัง:** แสดงเวลาคงเหลือก่อนถึงกำหนดชำระเงินวันที่ 15 ของทุกเดือน

## 🛠️ เทคโนโลยีที่ใช้
* **Frontend:** HTML5, Tailwind CSS, JavaScript (Vanilla JS)
* **Icons & Fonts:** FontAwesome, Google Fonts (Kanit)
* **Backend & Database:** Firebase Firestore (Cloud Database)

## 🚀 วิธีการใช้งานผ่าน GitHub Pages
1. สร้าง Repository ใหม่บน GitHub (เช่น `pea-kongklang`)
2. สร้างไฟล์ชื่อ **`index.html`** แล้วคัดลอกโค้ดระบบทั้งหมดไปวาง
3. สร้างไฟล์ชื่อ **`README.md`** แล้วคัดลอกโค้ดนี้ไปวาง
4. ไปที่เมนู **Settings** ➔ **Pages** ➔ เลือก Branch เป็น `main` / โฟลเดอร์ `/ (root)` ➔ กด **Save**
5. เว็บไซต์จะออนไลน์พร้อมใช้งานผ่านลิงก์ GitHub Pages ทันที!
